# Static Images

## Required Images:

### 1. favicon.ico
- Size: 16x16 or 32x32 pixels
- Format: .ico
- Location: `static/img/favicon.ico`
- Use: Browser tab icon
- Tool: https://favicon.io/ or https://realfavicongenerator.net/

### 2. hero-illustration.svg
- Size: Any (vector)
- Format: .svg
- Location: `static/img/hero-illustration.svg`
- Use: Hero section illustration
- Tool: https://undraw.co/ or https://storyset.com/

### 3. og-image.jpg
- Size: 1200x630 pixels (minimum)
- Format: .jpg
- Location: `static/img/og-image.jpg`
- Use: Social media sharing (Open Graph)
- Tool: Canva, Figma, or Adobe Photoshop

### 4. default.jpg (Avatar)
- Size: 300x300 pixels
- Format: .jpg
- Location: `media/avatars/default.jpg`
- Use: Default user avatar
- Tool: https://ui-avatars.com/ or any avatar generator

## Quick Setup:

1. Download or create the required images
2. Place them in the specified directories
3. The app will use these as fallbacks
