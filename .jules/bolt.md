## 2026-03-01 - Throttling Per-Request Middleware DB Writes
**Learning:** In Django applications with custom middlewares tracking user status (such as `ActiveUserMiddleware` updating `Profile.last_seen`), executing a database UPDATE query on every single HTTP request creates severe database write contention and unnecessary load under high traffic. Throttling these DB updates via `django.core.cache` (e.g., updating DB at most once every 300 seconds per user) eliminates ~99% of these write queries for active users while preserving tracking functionality.
**Action:** Always check custom middlewares for database queries on every request path and wrap non-critical state updates (e.g. `last_seen`, `last_activity`) with cache-based throttling using `cache.get()` and `cache.set()`.
