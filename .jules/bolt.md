## 2026-11-10 - QuerySet Annotation and Post Template N+1 Optimization
**Learning:** In Django, annotating a QuerySet (e.g. `Count('likes')`) clears the model's default `Meta.ordering`, which causes `UnorderedObjectListWarning` when passed to `Paginator`. To safely paginate annotated QuerySets while eliminating N+1 queries across related ForeignKey, ManyToMany, and reverse relation counts, the QuerySet must chain `.select_related()`, `.prefetch_related()`, `.annotate()`, and an explicit `.order_by()`. Additionally, model helper methods like `Post.total_likes()` should check `hasattr(self, 'like_count')` before falling back to `self.likes.count()` to prevent template calls from issuing per-item database queries.
**Action:** When optimizing Django list views with `Paginator`, always re-apply `.order_by(...)` on annotated QuerySets and check for annotated attributes inside model count helper methods.
