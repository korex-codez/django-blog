## 2026-03-31 - Annotations Clear Model Meta Ordering in Django
**Learning:** Calling `.annotate(like_count=Count('likes'))` on a Django `Post` QuerySet clears the default `Meta.ordering = ['-created_at']`. If passed directly to Django's `Paginator` without an explicit `.order_by('-created_at')`, Django emits an `UnorderedObjectListWarning: Pagination may yield inconsistent results with an unordered object_list`. Additionally, modifying `Post.total_likes()` to check `hasattr(self, 'like_count')` allows queries preloaded with `annotate()` to reuse the aggregated count without incurring N+1 `COUNT(*)` queries during template rendering.
**Action:** Always append an explicit `.order_by(...)` to annotated querysets when paginating, and pair annotations with `hasattr(self, '...')` model method guards.
