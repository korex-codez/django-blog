## 2026-11-07 - Django Post Card N+1 Query Elimination
**Learning:** Rendering post cards across post lists and the home page caused N+1 database queries due to accessing `post.category`, `post.author`, `post.tags.all()`, and calling `post.total_likes()` (which invokes `likes.count()`) on each post instance in the template. Chaining `.select_related('category', 'author')`, `.prefetch_related('tags')`, and `.annotate(like_count=Count('likes'))` on post querysets alongside checking `if hasattr(self, 'like_count'): return self.like_count` in `Post.total_likes()` slashes database query counts from 27 down to 6 on the home page.
**Action:** When creating or querying `Post` collections that will be rendered with author, category, tags, or like metrics, always apply `.select_related('category', 'author')`, `.prefetch_related('tags')`, and `.annotate(like_count=Count('likes'))` to prevent N+1 query cascades.
