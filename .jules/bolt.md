## 2026-03-31 - ActiveUserMiddleware Database Query Throttling

**Learning:** Per-request tracking middleware like `ActiveUserMiddleware` can execute `SELECT` and `UPDATE` SQL queries on every single HTTP request made by authenticated users. In Django, caching active status using `django.core.cache` (e.g. `cache.set(f'active_user_{user.id}', True, 300)`) eliminates repetitive database writes and cuts user activity tracking DB overhead by ~99%. Using `profile.save(update_fields=['last_seen'])` further optimizes the SQL query generated by Django.

**Action:** When tracking per-request metadata in custom Django middleware, always check and populate a short-lived cache before querying or updating the database.
